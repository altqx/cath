# Gamebryo SDK reference (optional)

```bash
./scripts/clone-gamebryo-ref.sh
```

Clones [sigmaco/gamebryo-v3.2.0.661](https://github.com/sigmaco/gamebryo-v3.2.0.661) into `vendor/gamebryo-ref`.

**Rules**

- Windows prebuilt Lib/DLL only — not used by the build
- Study `Include/` / docs for Ni\* / NIF concepts
- Do not copy proprietary sources into `src/cath`
- Do not redistribute the vendor tree
